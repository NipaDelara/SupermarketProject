# Supermarket Simulator

Group project for simulation course.

## Group Members
- Dornaraj Kharal

## Project Description
This project simulates customer flow in a supermarket system using the provided Simu_GUI framework.

## Project Structure
- `Simu_GUI/` : main Java simulation project
- `src/` : source code
- `lib/` : required libraries

## How to Run
1. Open the project in Eclipse
2. Make sure the required libraries are added
3. Run the main class
